# Coroner Role Module

Добавляет роль Коронера на аванпост с полным функционалом для работы с телами и документооборотом.

## Особенности:

### Роль Коронера
- Новая роль с доступом к моргу и медицинским зонам
- Специальная форма, халат и оборудование
- PDA с медицинским картриджем
- Печать коронера для документов

### Морг и хранилище тел
- Специальные зоны морга на аванпосту
- Мониторинг трупохранилища - если игрок вернется в тело, система оповестит коронера
- Специальные морговые лотки с системой мониторинга жизненных показателей

### Система обработки тел
- Конвейер для приема тел - принимает только мертвые тела
- Живых игроков отбрасывает и наносит урон
- За каждое тело начисляется 1000 кредитов

### Консоль коронера
- Управление кредитами от обработки тел
- Мониторинг зон хранения тел
- Вывод кредитов в виде голочипов

### Дрон сбора тел
- Автоматически собирает тела одиноких игроков с планет через час после смерти
- Телепортирует их в морг аванпоста
- Начисляет кредиты коронеру

### Документооборот
- Формы: свидетельство о смерти, отчет об осмотре тела, разрешение на выдачу тела
- Диспенсер форм
- Сканер документов для копирования
- Факс для связи с Центральным Командованием

## Установка:
Добавить в mod_celadon/_modpacks.dm:
```
#include "coroner/_modpack.dm"
```
