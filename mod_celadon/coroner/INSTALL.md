# Установка модуля Коронера

## Автоматическая установка
Модуль уже добавлен в `mod_celadon.dme` и готов к использованию.

## Ручная установка (если нужно)

1. Убедитесь, что в `mod_celadon/mod_celadon.dme` есть строка:
```
#include "coroner/coroner.dme"
```

2. Перекомпилируйте проект

## Добавление на карты

Для добавления морга коронера на карту используйте следующие объекты:

### Области (Areas):
- `/area/outpost/medical/morgue` - основная зона морга
- `/area/outpost/medical/morgue/office` - офис коронера  
- `/area/outpost/medical/morgue/storage` - хранилище тел (мониторится)

### Оборудование:
- `/obj/machinery/computer/coroner_console` - консоль управления
- `/obj/machinery/body_conveyor` - конвейер для приема тел
- `/obj/machinery/fax/coroner` - факс для связи с ЦК
- `/obj/structure/bodycontainer/morgue/monitored` - морговые лотки с мониторингом
- `/obj/structure/coroner_forms_dispenser` - диспенсер форм

### Предметы:
- `/obj/item/paper_scanner` - сканер документов
- `/obj/item/stamp/coroner` - печать коронера

## Тестирование

1. Создайте персонажа с ролью "Coroner"
2. Проверьте доступ к моргу и оборудованию
3. Протестируйте конвейер с мертвым телом
4. Проверьте систему мониторинга при возвращении игрока в тело
5. Убедитесь, что дрон сбора тел работает через час после смерти на планете

## Возможные проблемы

- Если роль не появляется в списке, проверьте компиляцию
- Если нет доступа, убедитесь, что доступы правильно настроены в ID карте
- Если не работает мониторинг, проверьте, что используются правильные области с флагом мониторинга
