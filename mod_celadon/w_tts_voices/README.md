### Изменения *кор кода*

- `code/__DEFINES/DNA.dm`								: Блоки днк дефайнов

- `code/modules/client/preferences_savefile.dm`			: Файл с настройками сейфов. Тут ясно
- `code/modules/client/preferences.dm`					: Файл того меню с настройками персонажа. Также сделано ннемного удобнее ориентирование
