# Ship Weapons System

Полнофункциональная система вооружения для космических кораблей, работающая с картой overmap.

## Основные возможности:
- Корабельные бои на overmap с дальностью до 30 тайлов
- Три типа оружия с уникальными характеристиками
- Система урона кораблей с разрушением
- Автоматические зарядные устройства
- Визуальные и звуковые эффекты
- TGUI интерфейс управления

## Компоненты:

### Консоль управления вооружением (`/obj/machinery/computer/ship_weapons`)
- Управление всеми орудиями корабля
- Система прицеливания по координатам overmap (1-30)
- Автоматическое обнаружение целей в радиусе
- Отображение здоровья целей
- Групповая стрельба всеми орудиями
- Индивидуальное управление каждым орудием

### Корабельные турели (`/obj/machinery/porta_turret/ship/weapon_system`)

#### Лазерные турели
- **Дальность**: 20 тайлов
- **Энергопотребление**: 300 единиц
- **Время зарядки**: 20 секунд
- **Урон**: 15 единиц корпуса
- **Особенности**: Не требуют боеприпасов, быстрая перезарядка

#### Баллистические турели
- **Дальность**: 15 тайлов
- **Энергопотребление**: 100 единиц
- **Время зарядки**: 10 секунд
- **Урон**: 20 единиц корпуса
- **Очередь**: 3 выстрела
- **Боезапас**: 100 снарядов
- **Особенности**: Высокая скорострельность, требуют боеприпасы

#### Ракетные установки
- **Дальность**: 25 тайлов
- **Энергопотребление**: 800 единиц
- **Время зарядки**: 60 секунд
- **Урон**: 35 единиц корпуса
- **Боезапас**: 10 ракет
- **Особенности**: Максимальный урон, медленная перезарядка

### Зарядные устройства (`/obj/machinery/ammo_loader`)
- Автоматическое пополнение боезапаса
- Подключение мультитулом к турелям в радиусе 3 тайлов
- Потребление энергии при работе (50/500 единиц)
- Различные типы для баллистики и ракет

### Система урона кораблей
- **Прочность корпуса**: 100 единиц у всех кораблей
- **Повреждение систем**: При 50% урона начинают ломаться двигатели
- **Критические повреждения**: При 75% урона ломается случайное оборудование
- **Уничтожение**: При 0% прочности корабль взрывается и удаляется

## Установка и использование:

### Базовая установка:
1. Разместить консоль управления (`/obj/machinery/computer/ship_weapons`) на корабле
2. Установить турели в пределах корабля
3. Подключить зарядные устройства мультитулом к турелям
4. Консоль автоматически найдет все орудия при запуске

### Быстрая установка через лендмарки:
```dm
// Лазерная турель с автоподключением
/obj/effect/landmark/ship_weapon_setup

// Баллистическая турель с зарядным устройством
/obj/effect/landmark/ship_weapon_setup/ballistic

// Полная установка с консолью
/obj/effect/landmark/ship_weapon_setup/full_setup
```

### Управление в бою:
1. Открыть консоль управления вооружением
2. Выбрать цель из списка или ввести координаты
3. Зарядить нужные орудия кнопкой "Charge"
4. Выстрелить отдельным орудием или всеми сразу
5. Следить за боезапасом и состоянием орудий

## Исследования:
Все компоненты доступны через протолат в категории "Weapons":
- `ship_weapon_laser` - Лазерная турель
- `ship_weapon_ballistic` - Баллистическая турель  
- `ship_weapon_explosive` - Ракетная установка
- `ammo_loader_ballistic` - Зарядное для баллистики
- `ammo_loader_explosive` - Зарядное для ракет

## Технические детали:
- Максимальная дальность: 30 тайлов overmap
- Автоматическое обнаружение целей в радиусе корабля
- Интеграция с существующей системой кораблей
- Поддержка всех типов кораблей и станций
- Совместимость с системой энергоснабжения

## Звуки и эффекты:
- Звуки зарядки и выстрелов для каждого типа оружия
- Визуальные эффекты выстрелов и попаданий
- Взрывы на целевых кораблях
- Объявления о повреждениях через систему связи

Система полностью интегрирована с существующим кодом и не требует изменений в базовых файлах (кроме минимальных добавлений с пометкой SHIPS_GUN_SYSTEM).
