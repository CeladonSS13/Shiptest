# Enhanced Ship Weapons System

## Адаптированные идеи из White Dream

Система корабельного оружия была улучшена с учетом идей из White Dream, но адаптированных под архитектуру Astra с виртуальными Z-уровнями и overmap координатами.

## Ключевые улучшения

### 1. Система точности и промахов
- **Базовая точность**: каждое оружие имеет базовую точность (60-95%)
- **Падение точности**: точность снижается с расстоянием
- **Минимальная точность**: гарантированный минимум (15%)
- **Визуальные промахи**: при промахе создается эффект рядом с целью

### 2. Расширенные характеристики оружия
- **Классы оружия**: Легкое, Среднее, Тяжелое
- **Типы урона**: Кинетический, Энергетический, Взрывчатый
- **Бронепробитие**: способность пробивать защиту
- **Скорость наведения**: влияет на точность по движущимся целям
- **Время перезарядки**: отдельно от времени зарядки

### 3. Многоступенчатая стрельба
- **Залповая стрельба**: оружие может стрелять очередями
- **Задержка между выстрелами**: реалистичная стрельба очередями
- **Координированный залп**: все оружие стреляет с небольшими задержками

### 4. Новые типы оружия

#### Лазерное оружие
- **Легкие лазеры**: быстрые, точные, низкий урон
- **Средние лазеры**: сбалансированные характеристики  
- **Тяжелые лазеры**: медленные, мощные

#### Баллистическое оружие
- **Легкие пушки**: быстрая стрельба очередями
- **Средние пушки**: сбалансированный урон и скорость
- **Тяжелые пушки**: высокий урон, медленная стрельба
- **Бронебойные**: высокое бронепробитие

#### Ракетное оружие
- **Легкие ракеты**: быстрая перезарядка
- **Тяжелые ракеты**: разрушительный урон
- **Торпеды**: дальнобойные, медленные
- **Кластерные**: множественные боеголовки

#### Новые экспериментальные типы
- **Лучевое оружие**: непрерывный урон, высокая точность
- **Плазменные пушки**: поджигающий эффект

### 5. Специализированные варианты

#### Противоистребительные
- **Точечная оборона**: высокая скорость наведения
- **Скорострельные**: множественные выстрелы

#### Снайперские
- **Дальнобойные**: минимальное падение точности
- **Высокоточные**: максимальная базовая точность

#### Штурмовые
- **Скорострельные**: быстрая перезарядка
- **Подавляющие**: большие очереди

## Тактические характеристики

### Точность по расстоянию
```
Точность = Базовая_точность - (Расстояние × Падение_точности)
Минимум = 15%
```

### Классы оружия
- **Легкое**: быстрое, точное, слабое
- **Среднее**: сбалансированное
- **Тяжелое**: медленное, мощное

### Типы урона
- **Кинетический**: эффективен против брони
- **Энергетический**: сбалансированный урон
- **Взрывчатый**: площадной урон

## Интерфейс консоли

Консоль управления оружием теперь показывает:
- Текущую точность для выбранной цели
- Класс и тип оружия
- Базовый урон и бронепробитие
- Время зарядки и перезарядки
- Количество выстрелов в очереди
- Скорость наведения

## Звуковые эффекты

Каждый тип оружия имеет уникальные звуки:
- Лазеры: характерный звук лазера
- Баллистика: звуки выстрелов
- Ракеты: звук запуска ракет
- Лучевое: звук эмиттера
- Плазма: звук плазменного импульса

## Совместимость

Все улучшения полностью совместимы с существующей архитектурой Astra:
- Используют overmap координаты
- Работают с виртуальными Z-уровнями
- Интегрированы с системой кораблей
- Сохраняют существующий UI
