# Система доступа офицеров Inteq к вендору

## Описание
Система ограничивает возможность сдачи документов в вендор Inteq только для авторизованных офицеров фракции.

## Авторизованные должности
Следующие должности Inteq автоматически получают доступ к сдаче документов:
- **Vanguard** (Капитан)
- **Master at Arms** (Варден)
- **Honorable Corpsman** (CMO)
- **Honorable Artificer** (Chief Engineer)

## Как это работает
1. При спавне персонажа с одной из офицерских должностей Inteq, его имя автоматически добавляется в глобальный список авторизованных офицеров
2. Первый заспавнившийся офицер генерирует уникальный 6-значный пароль для раунда
3. Через 30 секунд после спавна каждый офицер получает пароль большими красными буквами
4. При попытке сдать документы в вендор, система проверяет:
   - Имя игрока в списке авторизованных
   - Правильность введенного пароля
5. Если проверка не пройдена, вендор отклоняет документы

## Технические детали
- Глобальный список: `GLOB.inteq_authorized_officers`
- Глобальный пароль раунда: `GLOB.inteq_document_password`
- Регистрация происходит в `post_equip()` для каждого офицерского outfit
- Пароль генерируется один раз первым офицером (6 символов: A-Z, 2-9)
- Отправка пароля через 30 секунд после спавна
- Двойная проверка доступа в `attackby()` вендора: имя + пароль

## Защита вендора
Вендор имеет максимальную защиту от взлома и повреждений:
- **Неразрушимый**: Флаги `INDESTRUCTIBLE | LAVA_PROOF | FIRE_PROOF | UNACIDABLE | ACID_PROOF`
- **Защита от емага**: `emag_act()` блокирует попытки взлома
- **Невозможно разобрать**: `screwdriver_act()` блокирует разборку
- **Невозможно переместить**: `wrench_act()` блокирует откручивание

## Логирование (Admin Log)
Все важные события логируются в админ лог:
1. **Генерация пароля**: `INTEQ VENDOR: Password '[PASSWORD]' generated for this round.`
2. **Отправка пароля**: `INTEQ VENDOR: Password '[PASSWORD]' sent to [OFFICER_NAME].`
3. **Сдача документов**: `INTEQ VENDOR: [OFFICER_NAME] submitted documents using password '[PASSWORD]' and received [CREDITS] credits at [LOCATION].`

Все попытки взлома или разборки блокируются с выводом предупреждающего сообщения.
