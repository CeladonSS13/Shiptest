### Описание мода

Этот мод добавляет новую торговую шахтерскую консоль. Она будет размещаться только на Мете и Люксенбург.
Работает она так, консоль спавнит при создании корабля на себе лист с паролем. По этому паролю можно
войти в консоль. Консоль сканирует вашу банковскую картчоку на наличие денег и шахтерских очков.
Для разблокировки предмета, его нужно открыть за майнинг очки. А после купить за кредиты. Купленынй предмет
дроп подом упадет в зону доставки

Пароль не терять, его нельзя восстановить. Консоль надо вручную блокировать, выходя из сессии!
