# Ship Modules System

Система модулей кораблей, аналогичная модулям из Starsector.

## Особенности

- **Положительные модули**: Улучшения кораблей (Enhanced Engines, Reinforced Hull)
- **D-mods**: Отрицательные модули от повреждений (Damaged Engines, Hull Breach)
- **Фракционные модули**: Уникальные модули для каждой фракции
- **Консоль аванпоста**: Покупка, продажа и ремонт модулей
- **Пиратские модули**: Самодельные модули для пиратов

## Генерация модулей по фракциям

- **Независимые**: 0-1 случайный d-mod
- **Фракционные**: 1 уникальный фракционный модуль
- **Пираты**: 1-3 d-mods

## Консоль аванпоста

Три вкладки:
1. **Покупка**: Список доступных модулей для покупки
2. **Продажа**: Продажа установленных модулей
3. **Ремонт**: Ремонт поврежденных модулей

## Альтернативный ремонт для пиратов

- **Самодельный верстак**: Позволяет пиратам ремонтировать модули
- **Детали модулей**: Можно извлечь из поврежденных модулей
- **Ресурсы**: Требует больше материалов чем аванпост
- **Результат**: Создает пиратские самодельные модули

## Система извлечения модулей (Салваж)

- **Инструмент извлечения**: Специальный инструмент для снятия модулей
- **Консоль извлечения**: Устанавливается на захваченных кораблях
- **Чипы модулей**: Переносимые данные модулей
- **Шанс успеха**: Зависит от навыков и защиты корабля
- **Портативные наборы**: Для абордажных команд

## Черный рынок

- **Терминал черного рынка**: Для пиратских баз
- **Продажа модулей**: Украденные модули можно продать
- **Репутация**: Влияет на цены
- **Разыскиваемые модули**: Особо ценные модули

## Защита от извлечения

- **Security Package**: Модуль, затрудняющий извлечение
- **Ловушки**: Взрывные модули-ловушки
- **Уведомления**: Экипаж узнает о попытках извлечения

## Экономическая интеграция

- **Банковские карты**: Оплата на аванпосте через банковские счета
- **Голочипы**: Наличные для черного рынка
- **Цены продажи**: 50% от стоимости установки
- **Черный рынок**: 80% от стоимости аванпоста

## Файловая структура

```
mod_celadon/ship_modules/
├── code/
│   ├── ship_module_defines.dm      # Константы и дефайны
│   ├── ship_module_datum.dm        # Базовый датум модуля
│   ├── ship_modules_positive.dm    # Положительные модули
│   ├── ship_modules_negative.dm    # D-mods (отрицательные)
│   ├── faction_modules.dm          # Фракционные модули
│   ├── ship_integration.dm         # Интеграция с кораблями
│   ├── outpost_module_console.dm   # Консоль аванпоста
│   ├── pirate_repair.dm           # Пиратский ремонт
│   └── ship_modules_modpack.dm    # Модпак
├── tgui/
│   └── ShipModuleConsole.tsx      # TGUI интерфейс
├── _ship_modules.dm               # Основной файл
├── _ship_modules.dme              # DME файл
└── README.md                      # Документация
```
