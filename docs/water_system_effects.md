# Система динамической воды на основе эффектов

## Обзор

Система динамической воды теперь полностью основана на эффектах (`/obj/effect/water_overlay`), а не на турфах. Это позволяет создавать воду на любых открытых турфах без необходимости менять сам турф.

## Основные компоненты

### Водные эффекты (`/obj/effect/water_overlay`)

- **Базовый эффект**: `/obj/effect/water_overlay` - создает воду с заданным объемом
- **Предустановленные уровни**:
  - `/obj/effect/water_overlay/ankle_deep` - по щиколотки (100L)
  - `/obj/effect/water_overlay/waist_deep` - по пояс (200L)
  - `/obj/effect/water_overlay/chest_deep` - по грудь (300L)
  - `/obj/effect/water_overlay/neck_deep` - по шею (400L)
  - `/obj/effect/water_overlay/submerged` - полное погружение (500L)
  - `/obj/effect/water_overlay/full` - полная вода с защитой от удаления (500L)

### Турфы с водой

#### Новые турфы на основе эффектов (`/turf/open/floor/water_base`)

- **Базовый турф**: `/turf/open/floor/water_base` - только визуальный, без логики
- **С полной водой**: `/turf/open/floor/water_base/full` - автоматически создает 500L воды
- **С мелкой водой**: `/turf/open/floor/water_base/shallow` - автоматически создает 100L воды
- **Со средней водой**: `/turf/open/floor/water_base/waist` - автоматически создает 200L воды
- **С глубокой водой**: `/turf/open/floor/water_base/chest` - автоматически создает 300L воды

#### Старые турфы (`/turf/open/water/dynamic`)

Все еще работают, но теперь используют эффекты для обработки мобов.

## Инструменты для работы с водой

### Water Creator (`/obj/item/water_creator`)

- **Обычный клик**: добавляет 100L воды
- **Alt + клик**: добавляет 500L воды
- Создает новый водный эффект если воды нет, или добавляет к существующему

### Water Drain (`/obj/item/water_drain`)

- **Обычный клик**: убирает 100L воды
- **Alt + клик**: убирает всю воду
- Работает только с водными эффектами

### Full Water Creator (`/obj/item/water_creator/full`)

- Сразу создает 500L воды (полное погружение)
- Использует защищенный эффект `/obj/effect/water_overlay/full`

## Как использовать

### Создание воды в коде

```dm
// Создать водный эффект с 100L воды
var/obj/effect/water_overlay/water = new(target_turf)
water.add_water(100)

// Создать сразу полную воду
var/obj/effect/water_overlay/full_water = new /obj/effect/water_overlay/full(target_turf)

// Добавить воду к существующему эффекту
for(var/obj/effect/water_overlay/existing in target_turf)
    existing.add_water(200)
    break
```

### Создание турфов с водой

```dm
// В мапе используйте:
/turf/open/floor/water_base/full  // Полная вода (500L)
/turf/open/floor/water_base/shallow  // Мелкая вода (100L)
/turf/open/floor/water_base/waist  // Средняя вода (200L)
/turf/open/floor/water_base/chest  // Глубокая вода (300L)
```

## Особенности системы

### Распространение воды

- Вода автоматически распространяется на соседние открытые турфы
- Минимальный объем для распространения: 100L
- Скорость распространения настраивается через `spread_rate`

### Эффекты на мобов

- **100L+**: замедление при движении по грудь
- **400L+**: утопление (урон кислородом)
- **500L**: полное погружение (подводный оверлей)
- **1000L+**: давление воды (физический урон)

### Взаимодействие с турфами

- Эффекты воды работают на любых открытых турфах
- Турфы могут иметь встроенные водные эффекты
- Старые турфы `/turf/open/water/dynamic` все еще работают

## Преимущества новой системы

1. **Гибкость**: вода может быть создана на любом открытом турфе
2. **Производительность**: эффекты обрабатываются только при необходимости
3. **Совместимость**: старые турфы продолжают работать
4. **Простота**: легко добавлять и убирать воду через инструменты
5. **Визуальность**: турфы остаются визуальными, логика в эффектах
