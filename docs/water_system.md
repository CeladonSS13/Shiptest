# Система динамической воды

## Описание

Система динамической воды позволяет создавать реалистичную воду, которая может распространяться по тайлам, влиять на мобов и создавать различные игровые эффекты.

## Основные компоненты

### 1. Уровни воды

Вода имеет 6 уровней (0-5):
- **0 уровень (0 л)** - Воды нет
- **1 уровень (100 л)** - Вода по щиколотки
- **2 уровень (200 л)** - Вода по пояс
- **3 уровень (300 л)** - Вода по грудь
- **4 уровень (400 л)** - Вода по шею
- **5 уровень (500 л)** - Полное погружение

### 2. Эффекты на мобов

#### Дыхание
- **0-3 уровень**: Можно дышать нормально
- **4 уровень**: Сложно дышать, медленно накапливается урон от удушья
- **5 уровень**: Невозможно дышать без дыхательного аппарата

#### Движение
- **0-2 уровень**: Движение не замедляется
- **3-5 уровень**: Движение замедляется

#### Особые случаи
- **Лежачее положение**: Эффективный уровень воды увеличивается на 2
- **Дыхательные маски**: Позволяют дышать под водой
- **Ласты**: Убирают замедление при полном погружении

### 3. Распространение воды

Вода автоматически распространяется на соседние тайлы:
- Скорость распространения: 10 литров за тик
- Вода распространяется только на открытые тайлы
- Превращает обычные тайлы в водные

## Использование

### Создание воды

```dm
// Создание водного тайла
var/turf/open/water/dynamic/water_turf = new(location)
water_turf.add_water(300) // Добавить 300 литров

// Превращение существующего тайла в водный
var/turf/open/water/dynamic/new_water = existing_turf.ChangeTurf(/turf/open/water/dynamic)
new_water.add_water(200)
```

### Админские команды

- **Create Water** - Создать воду в указанном радиусе
- **Remove Water** - Удалить воду в указанном радиусе

### Тестовые предметы

- **Water Spawner** - Создает воду на тайлах
- **Water Remover** - Удаляет воду с тайлов

## Технические детails

### Файлы системы

- `code/__DEFINES/water.dm` - Константы и определения
- `code/datums/status_effects/water_effects.dm` - Статус эффекты
- `code/game/turfs/open/water_dynamic.dm` - Основная логика воды
- `code/modules/clothing/shoes/fins.dm` - Ласты
- `code/modules/movespeed/modifiers/water.dm` - Модификаторы скорости
- `code/modules/admin/verbs/water_admin.dm` - Админские команды

### Основные процедуры

- `add_water(amount)` - Добавить воду
- `remove_water(amount)` - Удалить воду
- `get_water_level()` - Получить уровень воды
- `spread_water()` - Распространить воду

## Расширение системы

Система легко расширяется:

1. **Новые типы жидкостей** - наследование от `/turf/open/water/dynamic`
2. **Дополнительные эффекты** - новые статус эффекты
3. **Взаимодействие с предметами** - проверка уровня воды в `afterattack()`
4. **Химические реакции** - интеграция с системой реагентов

## Производительность

- Обработка только активных водных тайлов
- Автоматическая остановка обработки при отсутствии воды
- Оптимизированное распространение
